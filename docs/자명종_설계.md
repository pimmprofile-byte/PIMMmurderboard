## 0. 이 판의 성격 — 후더닛이 아니다

> 「모두 겉으로는 범인을 찾으려고 할 테니까 범인은 비교적 쉽게 드러날 텐데,
>  오히려 다른 소기의 목적이 있을 거야.」

범인은 금방 나온다. 다섯이 전부 아주 열심히 찾을 거니까.
문제는 다섯이 전부 **찾는 척하면서 딴 걸 챙기는 중**이라는 것이다.

| | 겉으로 | 속으로 |
|---|---|---|
| **도둑** 키어런 | 누구보다 열심히 수사한다 | 새 유서를 이미 훔쳤다. 빨리 끝나야 주머니가 안 열린다 |
| **집사** 바질 | 정중하게 협조한다 | 죽였다. 다만 «왜»를 들키면 안 된다 |
| **하녀** 넬 | 슬퍼하며 도둑을 민다 | 운전기사가 자기 때문에 죽인 줄로 완전히 착각하고 그를 지킨다 |
| 의사 마시 | 신의 의술을 뽐낸다 | 반년째 독을 먹였다. 밥줄이 급해서 되살렸다 |
| 기사 토마스 | 아무 말도 안 한다 | 집사가 범인인 걸 안다. 소란 없이 도망치는 게 전부다 |

톤은 **캐주얼 · 블랙코미디**다. 다들 진지한 얼굴로 이기적이다.

## 1. 스누즈 — 판을 관통하는 기믹 하나

자명종 꼭대기에 버튼이 하나 있다.

> **반만 누르면** — 십 분 뒤에 다시 울린다
> **끝까지 누르면** — 멎는다

에드먼드 경은 삼십 년 동안 **반만** 눌렀다. 그것이 그의 손버릇이었다.
그리고 하녀 넬에게만 일러두었다.

> **「두 번 울리고도 내가 안 일어나거든, 그때는 들어와서 깨워라.」**

이 말을 들은 사람은 넬 하나다. **집사는 모른다.**

버튼이 눌린 **깊이**가 이 사건의 시계추다.

| | 버튼 | 알람 | 결과 |
|---|---|---|---|
| **어제 아침** | 끝까지 눌려 있다 | 한 번 울리고 말았다 | 넬이 들어갔다 → **살았다** |
| **오늘 아침** | 반만 눌려 있다 | 두 번 울렸다 | 아무도 안 들어갔다 → **죽었다** |

규칙이 완벽하게 작동한 날에 사람이 죽는다.

## 2. 배경

근대. **지중해의 섬 솔베니아**, 본토에서 배로 반나절. 섬의 절반, 사실상 전체가 솔베인 가문의 영지다.

솔베니아는 **소르트**라 불리는 향료로 유명한 땅이고, 에드먼드 솔베인 경은 그 소르트를 **독점**했다.
마흔 해 전, 유럽 전역이 이 향료에 미쳐 있었다. **솔베인 관**은 그 돈으로 지은 성채다.

그리고 「독점」이라는 말이 성립하려면, 소르트가 나던 다른 섬 하나가 없어야 했다. → 6절

집 안의 규칙 하나:
**아침 여덟 시부터 아홉 시까지, 아무도 당주가 머무는 복도를 지나지 말 것.** 오랜 옛날부터 있었다.

## 5. 오해 — 이 판을 제일 재미있게 만드는 것

**넬은 토마스가 범인이라고 굳게 믿는다. 틀렸다.**

비명을 지르고 창가로 갔더니 마당에 그가 담배를 물고 이 창을 올려다보고 있었다.
눈이 마주치자 담배를 급히 껐다. 언젠가 그가 마당에서 저 창을 보며 「저 방은 참 높은 데 있네」라고 한 적이 있다.
반년 동안 도망 계산만 했고, 그는 넬이 이 집에서 어떤지 다 안다.

그래서 넬은 하루 종일 **그를 지키려고 다른 사람을 범인으로 몬다.** 제일 만만한 건 낯선 도둑이다.

**토마스는 진실을 안다. 말할 생각이 없다.**
일이 커지면 본토에서 경찰이 오고, 경찰이 오면 도망을 못 간다.
게다가 다섯이 계속 붙어 있어서 아무하고도 단둘이 못 됐다.
그가 하는 고민은 「말할까 말까」가 아니라 「은식기를 몇 개까지 챙길까」다.

**이 오해는 진상 공개 전까지 안 풀린다.** 그리고 이것이 밤의 두 번째 동기가 된다 —
그가 나 때문에 사람을 죽였는데, 의사가 되살려놓는 바람에 **그게 다 헛일이 됐다.**

## 6. 왜 각자 그랬나

### 바질 — 로프탄

고향이 **로프탄**이다. 솔베니아 말고 **소르트가 나던 유일한 다른 섬**이었다.
「독점」이 성립하려면 그 섬이 없어야 했고, 마흔 해 전 솔베인 상회가 그렇게 했다. 지도에서 이름이 빠졌다.
바질은 열넷에 나왔고, 가족은 남아서 없어졌다. 서재 장부 명부에 「코트」가 넷 있고 옆의 숫자가 넷 다 같다.
장부 앞쪽에서 소르트 단가가 로프탄이 정리된 해부터 세 배로 뛴다.

삼십 년 전 이 집에 들어온 것은 우연이 아니다. 처음부터 그러려고 왔다.
그런데 당주는 늙고 친절하고 자기 이름을 정확히 불러주는 사람이었다. 그래서 삼십 년이 갔다.

어제 저녁 그가 웃으면서 로프탄 이야기를 했다. **삼십 년 안 한 게 미안해서가 아니라 기억이 안 나서였다.**

그가 감춰야 하는 것은 「죽였다」가 아니다. 그건 어차피 나온다. **「어디서 왔는가」**다.

### 넬 — 삼 년

열여섯에 들어왔다. 당주의 「다정함」이 삼 년째다. 무릎에 앉으라고 하고, 밤에 물을 가져오게 한다.
이 집 사람들은 그걸 「예뻐하신다」고 부른다. 넬도 그렇게 부른다. 다르게 부를 줄을 몰라서.
뱃삯이 없어서 못 나간다. 토마스와 반년째 도망 계산만 했다.

어제 아침 그가 죽은 걸 봤을 때 비명의 절반은 기쁨이었다. 그게 그녀의 제일 큰 비밀이다.

### 키어런 — 상속자였다가 아니게 된 사람

어머니 M이 이 집 하녀였고 그는 자기가 누구 아들인지 안다.
유서를 새로 썼다는 소문을 듣고 왔다. 자기 이름이 적혀 있을 줄 알았다.
적혀 있는 건 **집사 이름**이었다. 그래서 새 유서를 훔치고 옛 유서를 되돌려놨다.
옛 유서는 「내 피를 이은 자가 있을 시 그에게 전부」다. 그러니까 서류상 이 집은 지금 그의 것이다.

### 마시 — 밥줄

반년 전부터 조금씩 독을 탔다. 아프면 자주 부르고, 자주 부르면 왕진비가 오른다. 반년 새 세 배가 됐다.
오늘 아침 죽어버려서 밥줄이 끊길까 봐 한 시간을 매달려 되살렸다. 그 뒤로 십오 분마다 맥을 잰다.

### 구역과 카드

| | 구역 | R1 | R2 | R3 |
|---|---|---|---|---|
| A | 당주 침실 | A1 시신 · A2 자명종 · A3 창 | A4 잔 없는 물 자국 | A5 두 번째 아침 · A6 두 번 울린 자명종 |
| B | 온실·지붕 | B1 휘어진 유리지붕 | | |
| C | 서재 *(2막)* | | C1 금고 안의 유서 | C2 로프탄 장부 |
| D | 하인방·약장 | D1 약장 안의 두 병 | D2 왕진 장부 | |
| E | 차고 | E1 차고 앞과 일지 | | |
| Q | 당주에게 *(2막)* | | Q1 물맛 · Q2 봤나 · Q3 유서 | |
| P | 소지품 *(3막)* | | | P1 키어런 · P2 바질 · P3 넬 |

**Q 구역이 「질문권」이다.** 카드를 여는 것이 곧 묻는 것이고 답이 카드 본문이다.
당주는 **말을 못 한다** — 끄덕이거나 젓는 것만 된다. 그래서 답이 전부 고갯짓 하나로 돌아온다.
전부 `reveal: "public"`. 엔진을 안 고치고 질문 턴을 만든 방법이다.

### 각자를 가리키는 것

- **바질** — A2 버튼 / A3 안에서 잠긴 창 / A4 씻긴 잔 / D1 진정제 / B1 지붕 / **C2 로프탄 장부 + P2 지도**
- **넬** — A5 빈 병 / A6 반만 눌린 버튼·새로 감긴 태엽 / **P3 앞자락 얼룩 + 뱃삯 두 장**
- **키어런** — C1 봉투 접힌 자국이 두 벌 / Q3 새 유서는 금고에 있다는데 없다 / **P1 새 유서**
- **마시** — A1 손톱의 하얀 줄 / D1 이름표 없는 병 / D2 왕진비 세 배
- **토마스** — E1 짧게 탄 꽁초 하나 · 「08:00 차고 앞」 · 은식기 목록 「둘이면 두 배로 든다」

### 넬 배역의 전환

`MEMORY["nell"]`의 **seq 6** 항목이 어젯밤을 통째로 담고 있다. 3차 조사가 열릴 때 본인에게만 뜬다.
그 전에는 읽을 수 없다. **1·2막은 정말로 무고하게 연기하는 것이 이 배역의 값이다** —
다만 1·2막에도 할 일은 있다. 토마스를 지키려고 도둑을 미는 것.
