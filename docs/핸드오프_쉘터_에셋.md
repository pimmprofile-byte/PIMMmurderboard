## 0. 요청 요약

새 시나리오 **《쉘터》**(`scenarios/shelter.py`)가 코드로 들어갔는데 그림이 하나도 없다.
지금은 전부 그라데이션 대체본으로 뜬다. 아래 **12개 파일**을 만들어 `assets/`에 넣으면 끝난다.

**코드는 건드릴 필요 없다.** 파일 이름만 정확히 맞추면 클라이언트가 알아서 찾아 쓴다.
없으면 없는 대로 돌아가니, 하나씩 채워 넣어도 된다.

## 1. 만들 파일

### 인물 초상 4장

| 파일명 | 인물 |
|---|---|
| `assets/shelter_portrait_chahaewon.webp` | 차해원 |
| `assets/shelter_portrait_hanseonuk.webp` | 한선욱 |
| `assets/shelter_portrait_nojeonggeun.webp` | 노정근 |
| `assets/shelter_portrait_inhyesuk.webp` | 인혜숙 |

- **비율 3:4 세로**, 긴 변 1200px 안팎, webp
- **얼굴이 상단 1/3 안에** 들어와야 한다 — 목록에서 얼굴만 잘라 원형으로 쓴다
  (`object-position: 50% 22%` 로 크롭된다)
- 배경은 어둡게. 인물 뒤로 캠핑장/폐허가 흐리게 보이는 정도
- 기존 잠수정 초상(`assets/submarine_portrait_*.webp`)과 톤을 맞춰주면 좋다

### 오프닝 배경 4장

| 파일명 | 장면 |
|---|---|
| `assets/shelter_opening_calm.webp` | 해질 무렵의 캠핑장. 평화롭다. 아직 아무 일도 없다 |
| `assets/shelter_opening_scene.webp` | 밤. 관리동에 불이 켜져 있고 텐트 몇 동이 보인다 |
| `assets/shelter_opening_bg.webp` | 능선 너머로 올라오는 **녹색 연기**. 이 사건의 얼굴 |
| `assets/shelter_opening_body.webp` | 관리동 실내. 책상, 넘어진 사진 액자, 꺼진 등 |

- **16:9 가로**, 1920×1080, webp
- 하단 35%는 대사창이 덮으므로 중요한 것을 두지 말 것
- 사람 얼굴은 넣지 않는다(인물은 별도 스프라이트로 얹힌다)

### 배치도 1장

| 파일명 | |
|---|---|
| `assets/shelter_map.svg` | 캠핑장 배치도 |

`assets/submarine_map.svg`를 열어보면 구조가 그대로 있다. **그 파일을 복사해서 고치는 게 제일 빠르다.**

- viewBox `0 0 720 310` 유지
- 구역 6개. 각 구역에 `data-loc` 속성이 있어야 클릭이 먹는다

| `data-loc` | 이름 |
|---|---|
| `A` | 관리동 |
| `B` | 취사장 |
| `C` | 발전동 |
| `D` | 텐트터 |
| `E` | 창고 |
| `F` | 숲길 |

- 잠수정과 달리 **선체 윤곽·침수 표현은 필요 없다.** 산자락에 놓인 부지 배치면 된다
- 숲길(F)이 다른 다섯을 감싸는 형태면 좋다 — 실제로 그런 지형이다
- 텍스트는 `.z-name`(구역명), `.z-cnt`(카드 수) 클래스를 그대로 쓸 것

### 아직 안 만들어도 되는 것

- 효과음 — `assets/sfx/README.md` 참고. 지금은 합성음으로 돌아간다
- BGM — 아직 붙는 자리가 없다

## 2. 세계관 (그림 방향용)

녹색 연기가 대한민국을 덮은 지 열한 달. 건물이 삭고 음식이 썩었다. 인구는 절반 아래로
줄었고 줄어든 쪽은 **거의 전부 노인**이다. 다른 나라는 국경을 닫았다. 정부도 군인도 없다.

**평화누리 캠핑장** — 경기도 외곽 산자락. 주인 구본진(64)이 혼자 지키던 곳에 넷이 흘러들었다.
물을 나누고 밥을 지어 먹으며 몇 달을 지냈다. 그리고 어젯밤, 주인이 죽었다.

폐허물이지만 **황폐하기만 한 그림은 아니다.** 여기는 사람이 몇 달간 살림을 한 자리다 —
빨래줄, 개켜둔 담요, 손질한 텃밭. 그 위에 녹색이 얹힌다.

**색:** 바랜 카키·흙빛 위에 **독성 있는 녹색**이 하늘과 원경에만. 실내는 주황 등불.

## 3. 인물 (초상용)

> 세계관 설정상 **모두가 실제 나이보다 몇 살 더 들어 보인다.** 약의 부작용이다.
> 딱 두 사람만 예외적으로 다르게 그려야 한다 — 아래 ★ 표시.

### 차해원 · 31 · 여 · 前 최연소 국회의원, 재벌가 딸
관리 잘된 손. 옷은 낡았는데 걸음걸이가 다르다. 말이 험하고 직설적인데 웃을 때만 어려 보인다.
집안이 이 약을 만들어 뿌렸고, 그녀는 반대했다가 혼자 버려졌다.
→ **낡은 코트, 자세가 꼿꼿함, 시선이 정면. 냉소가 얼굴에 남아 있다.**

### 한선욱 · 26 · 남 · 연구원 ★
**또래보다 대여섯 살 어려 보인다 — 고등학생처럼 보여야 한다.** 자기 몸에 억제제를
시험해온 탓이다(다른 사람과 반대 방향). 안경, 후드, 낡은 백팩, 짧은 손톱.
항노화를 연구했고 그 논문이 이 재앙의 기반이 됐다.
→ **어리고 마른 체구. 눈만 지쳐 있다. 나이와 얼굴이 어긋나 보이게.**

### 노정근 · 42 · 남 · 前 특전사 상사
체격이 크고 자세가 곧다. 손등에 굳은살. 웃는 걸 본 사람이 없다.
퇴거 명령을 어기고 남았고, 지킨 사람들에게 배신당했다.
→ **군복은 아니지만 군인의 몸. 표정 없음. 정면을 안 본다.**

### 인혜숙 · 52 · 여 · 무직 (前 국정원 블랙요원) ★ — **진범**
**쉰둘인데 예순처럼 보여야 한다.** 실제 나이보다 열 살은 더. 손이 거칠고 자세가 굽었다.
머리를 늘 검게 물들인다(늙어 보이는 게 싫어서 — 이게 단서다).
→ **작고 굽은 체구. 위협적으로 보이면 안 된다 — 그게 이 인물의 트릭이다.**
→ 다만 손만은 정확하고 단단하게. **소매를 손등까지 내리고 있을 것**(왼쪽 손목의 자국을 가린다).

### 구본진 · 64 · 남 · 캠핑장 주인 — **피해자** (초상 불필요, 참고용)
프로젝트 사수 담당 고위 간부였다. 치매가 급격히 진행 중이었다.

## 4. 확인 방법

1. 파일을 `assets/`에 넣고 커밋
2. 서버를 띄우고 `/` → 참가자 → **쉘터** 선택
3. 초상은 배역 선택 화면에서, 배경은 오프닝에서, 배치도는 조사 화면에서 바로 보인다

파일명이 틀리면 **조용히 대체본이 뜬다**(에러가 안 난다). 안 보이면 이름부터 확인할 것.
