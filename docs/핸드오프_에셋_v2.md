## 2. 쉘터 — 세계관과 인물

### 세계

녹색 연기가 대한민국을 덮은 지 열한 달. 건물이 삭고 음식이 썩었다. 인구는 절반 아래로
줄었고 줄어든 쪽은 **거의 전부 노인**이다. 다른 나라는 국경을 닫았다. 정부도 군인도 없다.

**평화누리 캠핑장** — 경기도 외곽 산자락. 주인 구본진(64)이 혼자 지키던 곳에 넷이 흘러들었다.
물을 나누고 밥을 지어 먹으며 몇 달을 지냈다. 그리고 어젯밤, 주인이 죽었다.

폐허물이지만 **황폐하기만 한 그림은 아니다.** 여기는 사람이 몇 달간 살림을 한 자리다 —
빨래줄, 개켜둔 담요, 손질한 텃밭. 그 위에 녹색이 얹힌다.

**색:** 바랜 카키·흙빛 위에 **독성 있는 녹색**이 하늘과 원경에만. 실내는 주황 등불.

### 배치 (배치도 참고용 — 그림에 반영하실 필요는 없습니다)

관리동 · 취사장 · 발전동 · 텐트터 · 창고, 그리고 이 다섯을 **숲길이 감싸고 있다.**
부지로 들어오는 길은 남쪽 하나뿐이다.

### 인물

> 세계관 설정상 **모두가 실제 나이보다 몇 살 더 들어 보인다.** 약의 부작용이다.
> 딱 두 사람만 예외적으로 다르게 그려야 합니다 — ★ 표시.

#### 차서령 · 31 · 여 · 前 최연소 국회의원, 재벌가 딸
관리 잘된 손. 옷은 낡았는데 걸음걸이가 다르다. 말이 험하고 직설적인데 웃을 때만 어려 보인다.
집안이 이 약을 만들어 뿌렸고, 그녀는 반대했다가 혼자 버려졌다.
→ **낡은 코트, 자세가 꼿꼿함, 시선이 정면. 냉소가 얼굴에 남아 있다.**

#### 한도겸 · 26 · 남 · 연구원 ★
**또래보다 대여섯 살 어려 보인다 — 고등학생처럼 보여야 합니다.** 자기 몸에 억제제를
시험해온 탓이다(다른 사람과 반대 방향). 안경, 후드, 낡은 백팩, 짧은 손톱.
항노화를 연구했고 그 논문이 이 재앙의 기반이 됐다.
→ **어리고 마른 체구. 눈만 지쳐 있다. 나이와 얼굴이 어긋나 보이게.**
→ 귀엽게 그리지 마세요. 얼굴만 어리고 눈이 나이 먹은 상태입니다.

#### 노강일 · 42 · 남 · 前 특전사 상사
체격이 크고 자세가 곧다. 손등에 굳은살. 웃는 걸 본 사람이 없다.
퇴거 명령을 어기고 남았고, 지킨 사람들에게 배신당했다.
→ **군복은 아니지만 군인의 몸. 표정 없음. 정면을 안 본다.**

#### 인혜숙 · 52 · 여 · 무직 (前 국정원 블랙요원) ★ — **진범**
**쉰둘인데 예순처럼 보여야 합니다.** 실제 나이보다 열 살은 더. 손이 거칠고 자세가 굽었다.
머리를 늘 검게 물들인다(늙어 보이는 게 싫어서 — 이게 단서다).
→ **작고 굽은 체구. 위협적으로 보이면 안 됩니다 — 그게 이 인물의 트릭입니다.**
→ 다만 손만은 정확하고 단단하게. **소매를 손등까지 내리고 있을 것**(왼쪽 손목의 자국을 가린다).
→ 무해함 · 조로 · 손목 비노출, 이 셋이 동시에 성립해야 단서가 삽니다.

#### 구본진 · 64 · 남 · 캠핑장 주인 — **피해자** (초상 불필요, 참고용)
프로젝트 사수 담당 고위 간부였다. 치매가 급격히 진행 중이었다.
관리동 안쪽 방, 아내 사진이 놓인 책상 앞에서 발견됐다. 목에 손자국이 남아 있다.

## 3. 포스터 — 여기가 이번 작업의 핵심

### 3-1. 선행 3종이 이미 만들어 놓은 문법

`막차` · `졸업사진` · `잠수정` 포스터 세 장은 **같은 규칙으로 그려져 있습니다.** 새 두 장도
같은 규칙을 지켜야 한 줄에 나란히 놓았을 때 한 시리즈로 보입니다. 규칙은 이렇습니다.

| | |
|---|---|
| **사람** | 없음. 넣더라도 소실점 근처의 아주 작은 실루엣 하나까지 |
| **구도** | **1점 투시 실내.** 소실점이 화면 정중앙, 서 있는 눈높이(약 1.5m), 광각 |
| **천장 간판** | 화면 **상단 중앙에 불 꺼진 검은 직사각형 판**이 매달려 있음 — 세 장 다 있음 |
| **바닥** | 젖어서 반사됨. 관객 쪽으로 흘러오는 반사광이 화면을 아래로 끌어당김 |
| **광원** | 단 하나. 화면 깊은 곳에 있고, 그 하나만 채도가 높음 |
| **색** | 사건마다 **단색 지배** — 막차=차가운 청록, 졸업사진=청회색+녹색 점광, 잠수정=적색 |
| **바닥의 종이** | 세 장 다 **화면 아래쪽에 서류·사진이 흩어져 있음**. 이 시리즈의 서명 같은 것 |
| **분위기** | 중경에 옅은 안개/광선. 가장자리는 거의 검게 떨어지는 강한 비네트 |
| **질감** | 페인팅이 아니라 **포토리얼 3D 렌더 룩**. 미세한 필름 그레인 |

### 3-2. 반드시 지켜야 하는 안전영역 — 이게 제일 중요합니다

포스터는 **820×457 가로 이미지인데, 화면에는 세로 카드(3:4.2)로 잘려 나갑니다.**
`background-size: cover` 라서 **가로 가운데 약 40%만 실제로 보입니다.**

```
 ┌────────────────────────────────────────────────┐  820×457
 │        ░░░░░░│              │░░░░░░░░░         │
 │   안보임      │   ← 여기만 →  │   안보임         │
 │        ░░░░░░│   x 246~574  │░░░░░░░░░         │
 │              │▓▓▓▓▓▓▓▓▓▓▓▓▓▓│                  │  ← 아래 35%는
 └──────────────┴──────────────┴──────────────────┘     제목 글씨가 덮음
```

- **살아남는 영역: 가로 x 246~574 (가운데 328px), 세로 위에서 65%까지**
- 소실점·천장 간판·주광원은 **전부 이 안에** 들어와야 합니다
- 바깥 60%는 안 보이지만 **그래도 그려야 합니다** — 나중에 가로로 쓸 데가 생길 수 있고,
  선행 3종도 그렇게 만들어져 있습니다
- 선행본 우하단에 있는 **4각 반짝이 워터마크**(생성기 서명)는 크롭 밖이라 살아남았습니다.
  새로 만드실 때는 **없는 쪽이 낫습니다** — 없앨 수 없으면 우하단에 두세요

**1점 투시와 천장 간판 모티프는 지켜야 합니다.** 관리동 실내를 권합니다.

### 3-4. 《업경》 포스터

**지배색: 무채색에 가까운 잿빛 + 아주 옅은 청록 반사.** 이 사건은 **스포일러가 없어야
합니다** — 거울이 여러 개거나 상이 어긋난 그림은 답을 미리 말해버립니다. 절대 금지.

대신 「셋이 살던 한옥 집 안, 하나가 없다」만 그립니다. 불안은 색과 텅 빈 자리에서 옵니다.

**거울·겹친 상·반복된 물건은 절대 넣지 마세요 — 기믹이 새 나갑니다.**
