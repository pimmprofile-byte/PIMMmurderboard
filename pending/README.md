# pending — 에셋 프롬프트 작업 폴더

맵 구역 그림과 조사카드 그림을 만들기 위한 프롬프트 모음입니다.
**화풍은 실사가 아니라 잉크 그래픽노블**이고, 그건 이 게임에 이미 들어가 있는
잠수정 초상·쉘터 카드에서 실측한 사양입니다. `00_화풍_공통.md`가 그 사양입니다.

---

> **게임 화면에서도 볼 수 있습니다.** 관리자 모드 → **에셋 프롬프트** 탭.
> 이 문서들을 서버가 그대로 읽어 뿌리는 화면이라 여기와 항상 같습니다.
> 「합쳐서 복사」를 누르면 앞머리 + 톤 + 본문이 한 번에 붙어 나옵니다.

---

## 쓰는 순서

1. **`00_화풍_공통.md`** 를 먼저 읽습니다. 규격·앞머리 블록·리젝 규칙이 전부 여기 있습니다.
2. 시나리오 폴더로 들어가 `구역.md` 또는 `카드.md` 를 엽니다.
3. 각 항목의 **앞머리 블록 + 시나리오 톤 블록 + 개별 본문** 을 이어 붙여 넣습니다.
4. 나온 그림은 그 시나리오 폴더의 **`완성본/`** 에 파일명 그대로 넣어둡니다.
   (지금 비어 있습니다. 여기가 받는 자리입니다.)
5. 확인이 끝난 것만 `assets/` 로 옮깁니다. 옮기는 순간 화면이 집어갑니다.

**카드는 전수가 아닙니다.** 자명종만 전수로 뽑았고, 나머지 넷은 «그림이 붙었을 때
말이 늘어나는 카드»만 골랐습니다. 로그·CCTV·명부처럼 글자가 곧 내용인 카드는
그림이 오히려 방해가 되어서 뺐습니다. 각 `카드.md` 맨 아래에 뺀 카드와 이유를
적어뒀으니, 넣고 싶은 게 있으면 거기서 골라 말씀 주세요.

## 파일명 규약 — 틀리면 화면이 못 찾습니다

| 종류 | 규약 | 예 |
|---|---|---|
| 구역 배경 | `{시나리오id}_room_{art키}.webp` | `snooze_room_cellar.webp` |
| 카드 그림 | `{시나리오id}_card_{카드ID}.webp` | `snooze_card_A2.webp` |
| 인물별 카드 | `{시나리오id}_card_{카드ID}_{배역id}.webp` | `shelter_card_G2_riminhui.webp` |
| 금고 서류 | `{시나리오id}_doc_{키}.webp` | `snooze_doc_will.webp` |

시나리오 id는 화면에 뜨는 제목이 아니라 **코드상의 id**입니다.
「자명종」은 `snooze`, 「심연의 정원」은 `submarine` 입니다. (모듈 파일이
`abyss_garden.py`인데 에셋 접두사는 `submarine`입니다. 헷갈리기 쉬운 자리입니다.)

없는 파일은 자동으로 폴백됩니다 — **일부만 넣어도 화면이 안 깨집니다.**

## ⚠ 먼저 알아둘 것 — 구역 그림이 아직 안 붙는 판이 셋 있습니다

구역 배경은 시나리오가 `ROOMS`(구역별 `art` 키 목록)를 들고 있어야 화면이 찾아갑니다.

| | `ROOMS` | 구역 그림 |
|---|---|---|
| `shelter` · `submarine` | 있음 | 파일만 넣으면 바로 뜹니다 |
| `snooze` · `subway` · `graduation` | **없음** | 파일을 넣어도 안 뜹니다 |

밑의 셋은 **`ROOMS` 를 붙이는 코드 작업이 따로 필요합니다.** 이번 건은 프롬프트
정리라서 코드는 손대지 않았습니다. 각 `구역.md` 에 붙일 `ROOMS` 초안을 적어뒀으니,
그림이 나온 뒤에 말씀 주시면 붙이겠습니다.

(그래서 `snooze_room_bedroom.webp` 가 이미 있는데도 지금 화면에 안 나옵니다.)

카드 그림과 금고 서류 그림은 배선이 이미 다 되어 있어서 **넣는 즉시 뜹니다.**
