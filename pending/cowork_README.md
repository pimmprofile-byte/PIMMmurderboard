## 2. 원칙 — 이것만 지켜주세요

1. **아무것도 지우지 않습니다.** 전부 «이동»입니다.
   저장소에는 webp로 변환된 판본만 있고, **드라이브의 jpeg 원본이 유일한 원본**입니다.
   다시 뽑을 일이 생기면 원본이 필요합니다.
2. **`_확인필요` 폴더는 건드리지 않습니다.** 쓸 자리가 아직 안 정해진 물건입니다.
3. **저장소(`assets/`)는 손대지 않습니다.** 그건 제가 합니다.
4. 이름이 UUID인 파일도 **지우지 않습니다.** 이미 설치된 잠수정 카드 그림의 원본입니다.

## 5. 앞으로의 규칙 — 다음 업로드부터

새 그림을 올릴 때는 **`_pending` 루트가 아니라 위 하위폴더 안에** 넣습니다.
그리고 **가능하면 최종 파일명으로 저장해서 올려주세요.** 그러면 대조가 필요 없어집니다.

| 종류 | 파일명 규약 | 예 |
|---|---|---|
| 구역 배경 | `{시나리오id}_room_{키}.webp` | `snooze_room_cellar.webp` |
| 카드 그림 | `{시나리오id}_card_{카드ID}.webp` | `snooze_card_A2.webp` |
| 인물별 카드 | `{시나리오id}_card_{카드ID}_{배역id}.webp` | `shelter_card_G2_riminhui.webp` |
| 인물 초상 | `{시나리오id}_portrait_{배역id}.webp` | `snooze_portrait_basil.webp` |
| 오프닝 배경 | `{시나리오id}_opening_{컷}.webp` | `snooze_opening_clock.webp` |
| 금고 서류 | `{시나리오id}_doc_{키}.webp` | `snooze_doc_will.webp` |
| 포스터 | `poster_{시나리오id}.jpg` | `poster_snooze.jpg` |

시나리오 id는 화면 제목이 아니라 **코드상의 id**입니다.
「자명종」은 `snooze`, 「심연의 정원」은 `submarine`입니다.
(모듈 파일은 `abyss_garden.py`인데 에셋 접두사는 `submarine`입니다. 제일 헷갈리는 자리입니다.)

**어떤 그림이 필요한지, 무엇이 보여야 하는지는 `pending/` 안의 프롬프트 문서에 다 있습니다.**
게임 화면에서 **관리자 모드 → 에셋 프롬프트** 탭으로도 그대로 볼 수 있고, 거기서
「합쳐서 복사」를 누르면 앞머리 + 톤 + 본문이 한 번에 붙어 나옵니다.
