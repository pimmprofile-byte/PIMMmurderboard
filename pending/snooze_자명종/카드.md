# 4. 금고 서류 2장 (`_doc_`)

카드가 아니라 **추가정보 첫 슬라이드**에 들어가는 그림입니다.
배선은 이미 되어 있어서 **넣는 즉시 뜹니다.**
I1·I2 카드 그림과 **같은 물건을 다른 각도로** 그리세요 — 슬라이드는 문서를 «읽는» 자리라
좀 더 정면에서, 좀 더 크게 잡습니다.
